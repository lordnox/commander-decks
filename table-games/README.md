# Table games

Replays from the `simulate-table` skill. A run writes `<slug>.json` (the log)
and `<slug>.html` (a self-contained viewer: felt table, life totals, stack,
step slider, card art on hover). Open the HTML in a browser; GitHub will not
render it inline.

Both are gitignored so ordinary runs stay scratch. To keep a game, `git add -f`
the two files and add a `<slug>.md` recap, since neither JSON nor HTML is
readable in a pull request.
