# Commander Decks

A conversation-driven workspace for importing, resolving, categorizing, assessing, and improving Magic: The Gathering Commander decks. Submitted lists stay unchanged; card data is cached from Scryfall for reuse.

## Deck primers

Grouped by [Commander bracket](https://mtgcommander.net/index.php/brackets/), with each deck's exact position after its name. The code after it is that deck's [ranking](.agents/skills/rank-deck/SKILL.md), scored 1–10 and always in the order `J`ank, `F`un, `M`ean (oppressiveness), so `J9 F8 M7` reads as very janky, fun, and fairly mean. The badges after it score the deck against its own goals. Underneath are the deck's strongest [Archidekt deck tags](.agents/skills/tag-deck/archidekt-tags.json); each primer repeats all of this as labelled badges, with mean scores of 7 or more marked red.
